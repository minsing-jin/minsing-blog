## 3과목 : PC 운영 체제
#### 로더(패치, Fetch, 적재기)
: 주기억장치(혹은 cpu)로 가져온다는 말 나오면 이거 찍기!

- 로더의 기능 :할당, 링킹, 재배치

### 윈도우 98
**- Alt + F4**: 창닫기(프로그램종료)/윈도우 종료
**- Ctrl + ESC**: 시작메뉴 호출

### Dos
#### 내부명령어(4글자 이하!!)
**- REN**: 명령 프롬프트에서 설정된 경로(폴더) 내의 모든 파일의 파일명을 입력한 조건대로 이름을 바꿔주는 REName’합니다.
-> 동일한 디렉터리 내에서만 가능하나 같은 이름의 파일명이 추가되면 에러가 발생할수 있습니다
-> ‘REN [파일명1] [파일명2]’형식의 명령문은 [파일명1]을 [파일명2]로 REName하는 것이므로 [파일명1]을 명령대로 새로 바꿔 줄 새 [파일명2]가 같은 디렉토리에 이미 존재한다면, [파일명2]가 디렉토리 내에서 중복되어 오류가 발생할 것입니다.

**- DIR(목록보기)**:
/OE: 파일 확장자의 **알파벳순**으로 출력
/S: 지정된 디렉토리, 서브 디렉토리의 파일까지 **모두 출력**
/P: **화면 단위로 출력**하고 일시 정지
/ON: 이름순 오름차순
/W: 한줄에 5열씩 파일이름, 확장자 보여줌

#### 외부명령어(5글자 이상!!)
### UNIX
- lp : 텍스트 인쇄
- cat : 파일의 내용을 화면에 출력.
- chown : 파일의 오너 또는 그룹(소유권)을 변경. (choose own)
- pwd : 현재 작업 디렉토리 경로를 표시 (path way directory)

#### 구성
**- 커널(kernel):** CPU, 메모리, 하드디스크 등의 하드웨어를 **관리**하여 스케줄링, 기억장치관리, 파일관리, 시스템 호출 인터페이스 등의 기능을 제공/ OS의 핵심구성요소 / 주기억장치/ 도스의 MSDOS.SYS
**- 쉘:** 명령해석 / 도스의 COMMAND.COM
**- 유틸리티** : 명령어
순서
