# Conclusion
Sort values based on a lambda function. I guess I should learn by looking at the examples.


# Parameter Groups
## key
Ascending order: sorted(a, key=lambda x:x[0])
Descending order: sorted(a, key=lambda x:-x[0])


## reverse
True: Descending order (the numbers get smaller)
False(default): Ascending order
