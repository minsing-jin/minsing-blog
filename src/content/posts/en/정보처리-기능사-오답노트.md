#### Fractional Number-System Conversion

### DOS
#### Internal commands (4 letters or fewer!!)
**- REN**: REName, which changes the names of all files within the path (folder) set at the command prompt according to the specified conditions.
-> It is only possible within the same directory, but an error may occur if a file with the same name is added
-> The command statement in the form ‘REN [filename1] [filename2]’ RENames [filename1] as [filename2], so if the new [filename2] that will replace [filename1] as instructed already exists in the same directory, [filename2] will be duplicated within the directory and an error will occur.


**- DIR (view list)**:
/OE: Output in **alphabetical order** of file extensions
/S: **Output all files**, including those in the specified directory and subdirectories
/P: **Output by screenful** and pause
/ON: Ascending order by name
/W: Display file names and extensions in 5 columns per line


#### External commands (5 letters or more!!)
### UNIX
- lp : Print text
- cat : Display the contents of a file on the screen.
- chown : Change the owner or group (ownership) of a file. (choose own)
- pwd : Display the path of the current working directory (path way directory)
