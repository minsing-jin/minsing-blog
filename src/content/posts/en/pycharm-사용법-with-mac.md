**This document is meant to be used like an encyclopedia. Use command + F to find the feature you want.**


### Shift + Shift
- Find files
- Finds files that contain the desired word.


### command + click
- Finds files that use this method, variable, class, and so on.
- Tells you which files use it through usage.


### Click the target icon
- Finds the child classes that implement the functions of abstract methods in an abstract class.
