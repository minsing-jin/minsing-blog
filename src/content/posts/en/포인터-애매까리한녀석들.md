Summary:
<The basic principle is that a pointer is a variable that points to an address; keep this in mind>
1. When using pass-by-pointer
- Pass an address variable
- In that case, the function's argument must be given an address
	- That is, pass a pointer, an address variable, or the address value using &~


2. Use * to point to the value at an address
- Since it points to a value, passing it by pointer allows operations
or manipulation of the values being pointed to
- In that case, if you pass it like *pointer, how should it be manipulated as *pointer inside the other function?
