1. Integrate Git with the default template when creating a container


1-1. Set a token in the user information


2. Select the desired branch or create a new one, then click the + button to select the unstaged files to upload to GitHub


3. Commit using the button below


4. Push using the push button above the History button



-------------------------------------------


**cf) Error note**
1. If the push fails
1-1. Click the event next to History. If it says fatal: authentication failed for "GitHub link"
- Follow the instructions at the link below to generate new token that can access the GitHub API, copy the token, then click the file-shaped gear button next to Pull in Goorm IDE and copy-paste it into the access token field in the user information
