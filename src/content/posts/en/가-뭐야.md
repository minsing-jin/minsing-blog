# One-line explanation
Using annotations


1. : is a comment describing the parameters. 
2. -> is a comment describing the return value.


By specifying the data types for both, you can avoid inputting incorrect data types or having to look up the data types of output values individually.



# Example code explanation


## Class attributes and regular attributes
```python
from typing import ClassVar, Dict

class BasicStarship:
    captain: str = 'Picard'               # 기본값이 있는 일반 속성
    damage: int                           # 기본값이 없는 일반 속성
    stats: ClassVar[Dict[str, int]] = {}  # 클래스 속성
```


## Functions
```python
def executeCallback(num:int, callback:Callable[[int, int], str]):
    p: callback(int, int) = callback(num, 10)
    p.lower()
    
def executeCallback(num:int, callback:Callable[[None], None]):
    callback()
```


As in the example above, you can add information about a variable like a comment between the variable and =.
