# 🍳 동기
jetbrain 애용자로써 현재 Clion과 학교 계정으로 pycharm 프로페셔널 에디션을 mac os에서 사용하고 있다. 무거운 프로그램들인 만큼 개발을 위해 필요한 환경들과 기능, 패키지 관리등이 풍부하다. 현재 리눅스에서는 vsc만 설치되어있지만 다른 IDE인 pycharm도 설치를 해보고자 했다.

# 🍳 튜토리얼
## 설치
아래 명령어를 입력하면 자동으로 설치가 된다.
```
sudo snap install pycharm-community --classic
```
![](/images/velog/ebe410cb79bc1cee.png)

## 간단한 과정
프로그램들 설치하면 항상 나오는 term들에 대해서는 agree를 눌러줘야 사용가능하다.
![](/images/velog/fea3c8ef32f989fd.png)

pycharm을 사용할 준비가 끝났다. 개발 lets go~
![](/images/velog/ee31addc824b8c3a.png)


# 🍳 느낀점
IDE를 설치하는것은 큰 어려움은 없다. 규모가 있는 프로젝트를 진행할때 필요한 패키지들이나 추가적인 개발환경들을 설치 해보는 상황에서 난이도가 생길것으로 보인다. 혹은 특정 프로그램이 리눅스 환경에서는 지원이 안될때가 어려움을 겪는 상황이라고 생각이 든다.
